## Intent

The coordinator's status reports are now driven by a recurring project routine that fires once an hour, at about
:05 past each hour from 10 to 22 Europe/Warsaw. The project harness allows no routine shorter than one hour, so a
30-minute report cannot be scheduled. `context/workflow.json` still says `autonomy.reports: { every: 30,
hours: "10:00-22:30" }`, which suggests a cadence nobody can keep. Make the configuration say hourly.

Requested by the owner on 2026-10-12 in the project chat: change the settings so they no longer suggest half an
hour.
