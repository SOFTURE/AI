# Research: deploy-row-count-config

Date: 2026-10-06. Sources: `tools/deploy/` on `master` (DP-3 `row-counts`, DP-4 `deploy.json`, DP-5 `init`), the
DP-3 archive (`context/archive/2026-10-05-deploy-db-guard/`).

## Questions

1. **How is `deploy.json` read today?** Only by `verify` (`src/cli/verify-command.ts`): `--config` (default
   `deploy.json`, relative to the working directory), `parseDeployConfig` turns zod issues into `path: message`
   lines, an unreadable file or an invalid one is exit 1. The root schema is a strict object whose keys grow by item
   (`$schema`, `verify`), so `database` is a new optional key. `row-counts` can share the reading with `verify`.
2. **What does a valid table name look like?** `row-counts.ts` has the pattern (`table` or `schema.table`, lower
   snake case) and `parseTableList` checks a comma list against it. The schema uses the same pattern, so a name the
   flag refuses the file refuses too.
3. **Who runs `row-counts` without `--tables`, and where?** On the server, `init`'s `deploy.sh` (DP-5) runs it with
   `--tables="$ROW_COUNT_TABLES"`, baked in at `init` time. The server folder holds `docker/prod/` and `deploy.sh`
   only; `deploy.json` lives in the app's repository. So `deploy.sh` cannot read the list until the release ships
   `deploy.json` to the server, which is DF-7's change (it owns `deploy.sh` and the shipped files). This item gives
   the CLI the key; moving `deploy.sh` and `init` onto it is a new gap, after DF-7.
4. **Precedence.** `--tables` given: the file is not read (a broken or absent `deploy.json` does not matter).
   `--tables` and `--config` together is ambiguous and a usage error. Without `--tables`: the file named by
   `--config` (default `deploy.json`) must exist, be valid and hold the list; otherwise the command says how to
   name the tables.
5. **The JSON Schema** is generated by `npm run schema -w @softure-ai/deploy`; `tests/schema.test.ts` fails when
   it is stale or a key lacks a description.

## Answer

A `database` object with an optional `rowCountTables` (at least one name, unique, the `row-counts` pattern);
`row-counts` reads it through a reader shared with `verify`. `deploy.sh` and `init` follow after DF-7 (new gap).
